The Stack

Tauri v2 + this HTML

The panel above is the whole front end. Tauri wraps it in a native window on both Windows and macOS, and only a handful of Rust lines are needed for the desktop behaviour.

Window Config

Four flags do the hiding

transparent, decorations: false, alwaysOnTop and skipTaskbar. The slide-off is CSS; the window itself stays put at full size.

Storage

One local SQLite file

Tasks, colours, notes and one row per tracked interval. Totals reset at midnight and every past day stays queryable for the history view.
